# Textures originales

Images 16x16 dessinées pour BlocNav (par `tools/generate_textures.py`).
Ce ne sont **pas** les textures du jeu.

- Tu peux remplacer une image par la tienne (même nom, carrée, idéalement 16x16).
- `grass.png`, `leaves.png` et `water.png` sont **grises** : l'app les colore
  (couleurs `tint` dans `js/textures.js`). Une image de remplacement pour ces trois-là
  doit donc être grise aussi.
- `icons/` contient les icônes pixel-art (lieux, flèches de virage, boutons).

Pour utiliser les textures de ton jeu, n'ajoute rien ici : utilise
**Réglages → Importer un pack** dans l'app (elles restent sur le téléphone).
